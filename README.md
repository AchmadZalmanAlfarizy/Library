B. Deskripsi Aplikasi

Manajemen Perpustakaan adalah aplikasi pengelolaan perpustakaan yang dirancang untuk membantu petugas dalam mengatur seluruh aktivitas operasional, seperti pendataan buku, pengelolaan anggota, proses peminjaman, hingga penyusunan laporan. Aplikasi ini menyediakan fitur yang terstruktur seperti antrian daftar buku, kategori buku, daftar peminjaman, laporan peminjaman, daftar anggota, profil, serta riwayat peminjaman.
Dengan antarmuka sederhana dan alur kerja yang jelas, aplikasi ini memudahkan petugas perpustakaan dalam mengelola data secara cepat, akurat, dan efisien sehingga pelayanan kepada pengguna menjadi lebih optimal.
